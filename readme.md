# Assignment1

This repository contains a simple Python `Adder` class and unit tests.

## Project Structure

- `src/Adder.py` - Implements the `Adder` class.
- `tst/AdderTest.py` - Unit tests for the `Adder` class.

## Run Tests

From the repository root:

```bash
python -m unittest tst/AdderTest.py
```
